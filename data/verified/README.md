# Verified Dataset

Letakkan di sini hasil verifikasi label.

Setiap record sebaiknya memiliki kolom tambahan:

- `verification_source`  (phishtank, virustotal, whois, manual, …)
- `verification_status`  (confirmed / rejected / unknown)
- `verified_at`          (ISO-8601)
- `verifier_notes`

Jangan menganggap hasil scraping sebagai bukti phishing.
Online gambling tetap disimpan sebagai kategori terpisah.
